# Hana快捷指令（quick-cmd）

在 Hana Agent 的输入栏放一个快捷指令入口：点开在输入框上方挑指令，发送时把指令内容拼到本次用户提示词的头或尾。

## 解决什么问题

常用命令和提示词每次都要手打或复制粘贴，重复、打断节奏。这个应用把它们收成一张按 agent 分类的指令表：点一下、按个数字键，就把这条指令挂到这次输入上。

## 用法

- **输入栏的 ⌘ 图标**：点开输入框上方的面板，面板列出当前 agent 的指令。
- **选择**：点条目，或按数字键 `1`–`9`（先匹配每条指令自己配的快捷键，没匹配上就按列表序号）；再点一次或点标签上的 `×` 取消。
- **发送**：被选中的指令内容按各自设置拼到本次用户提示词的头或尾，不带任何标记；拼完即清，只作用于这一条消息。

## 配置

设置 → Hana快捷指令：

- 每个 agent 一张独立的指令表；没单独配置的 agent 继承「默认（兜底）」表。
- 每条指令可配：指令名、指令内容、拼接位置（头部／尾部）、快捷键（1–9）、是否启用。
- 可整体关闭「允许 Agent 通过工具管理快捷指令」。

## 给 Agent 的工具

| 工具 | 作用 |
|---|---|
| `quickcmd_open` | 在输入框上方打开面板 |
| `quickcmd_list` | 列出某个 agent 的指令 |
| `quickcmd_upsert` | 新增或修改一条指令 |
| `quickcmd_delete` | 删除一条指令 |

后三个可在设置里整体关闭。

## 权限

声明的能力与用途：

| 能力 | 用途 |
|---|---|
| `app/input.status` | 在输入栏显示 ⌘ 图标（并显示已选条数） |
| `app/input.panels` | 在输入框上方挂自己的面板 |
| `app/hooks.session-input` | 发送前把选中指令拼进本次用户输入 |
| `app/tools.expose-to-model` | 把上面四个工具提供给模型 |
| `app/agents.read` | 设置页列出 agent |
| `app/sessions.read` | 把会话对应到 agent |

无外部服务、无网络请求、无凭据；数据只存在应用自己的存储里。

## 已知边界

平台目前没有让应用「往输入框内部插 chip」的接口，应用能用的输入框座位只有输入栏按钮、输入框上方横幅、输入框上方面板。所以「指令名标签」渲染在面板底部那条紧贴输入框上沿的选择条上；功能（选中／取消／发送拼接）不受影响。
